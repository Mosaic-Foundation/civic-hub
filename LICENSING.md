## Plugins

Plugins don't have to be AGPL. As an additional permission under section 7 of the AGPL, the Mosaic Foundation allows a plugin (a package that adds a process type or other feature to a hub) that works with Civic Hub only through the published plugin SDK and package contract to be licensed under any terms its author chooses. Running a plugin in a hub, or building and testing it with the plugin SDK and conformance suite, does not by itself bring the plugin under the AGPL.

The AGPL still applies to Civic Hub itself, including the hub engine carried inside the plugin SDK, and to any changes you make to them.
